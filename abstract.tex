The Next Generation Triggers (NGT) project aims to research and develop novel technologies for detector trigger systems at the High-Luminosity LHC (HL-LHC) and future colliders.
A central component of this effort is the expansion of the CMS High-Level Trigger (HLT) system toward a data-scouting paradigm, where all events accepted by the Level-1 trigger are reconstructed and recorded in a compact, storage-efficient format suitable for prompt physics analysis, at \SI{750}{\kilo\hertz}.
With this in mind, the HLT event reconstruction is being fundamentally rethought to achieve offline-quality performance within stringent real-time processing and storage constraints.
Advanced algorithms optimized for heterogeneous architectures, particularly GPUs, are applied to the CMS Phase-2 tracker reconstruction.
This work evaluates extended pixel tracking variants against full tracking configurations, incorporating Patatrack parameter tuning, duplicate cleaning, and a GPU-accelerated deep neural network pixel track selector.
We demonstrate that extended pixel tracks approach tracking  efficiencies comparable to full tracking, while delivering a $\sim$12\% reduction in average processing time and a $\sim$30\% savings in GPU memory.
This marks an encouraging step for achieving pixel-only tracking for the HLT scouting.
